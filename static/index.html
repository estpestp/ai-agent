AI Agent Server

Python 코드가 요청을 보내고, 이 서버가 JSON 답변을 돌려주는 API야. 서버 상태와 AI 설정 여부를 확인할 수 있어.

① Health check서버가 실행 중인지 확인
② POST /api/ask질문과 페이지 요약 전송
③ JSON responseanswer 또는 오류 정보 반환
GET /health
POST /api/ask
Authorization: Bearer YOUR_API_TOKEN

API_TOKEN으로 보호돼. 실제 AI 답변을 쓰려면 서버 환경변수에 AI_API_KEY와 AI_MODEL을 설정해야 해. API 키를 브라우저에 넣지 마.
